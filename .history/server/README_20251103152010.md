# CLG QP Server

Go backend that exposes REST APIs for authentication, prompt management, and submission evaluation.

## Setup

```bash
cp .env.example .env
# update MongoDB URI, JWT secret, admin registration code, and Gemini AI service URL

# install dependencies
cd server
go mod tidy

# run the server
PORT=8000 go run ./...
```

The server automatically creates MongoDB collections and indexes when requests are processed. Files uploaded by users are persisted in the `uploads` directory (configurable via `UPLOADS_DIR`).
