# CLG QP Client

React front-end for the question paper evaluation portal. Includes:

- Role-based login (admin and user)
- Admin console for maintaining the AI grading prompt
- User workspace for uploading answer scripts (images or PDFs)
- Result history with reasoning from the AI service

## Quick start

```bash
cp .env.example .env
npm install
npm run dev
```

Set `VITE_API_BASE_URL` in `.env` if the backend runs on a different host/port.
