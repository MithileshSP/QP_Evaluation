# CLG QP Client

React front-end for the question paper evaluation portal. Includes:

- Single-page workspace that lets you edit the AI grading prompt
- File uploader for images or PDFs
- Automatic AI scoring with reasoning and history

## Quick start

```bash
cp .env.example .env
npm install
npm run dev
```

Set `VITE_API_BASE_URL` in `.env` if the backend runs on a different host/port.
