# AI Service

Node.js microservice that wraps the Gemini API to evaluate handwritten answer sheets.

## Setup

```bash
cp .env.example .env
# Edit .env and set GEMINI_API_KEY (keep it private!)

cd ai_service
npm install
npm run dev
```

The service listens on port `8100` by default and exposes:

- `GET /health` — lightweight readiness check.
- `POST /evaluate` — accepts `{ prompt, constraints, files }` payloads from the Go backend.
- `POST /assessments/analyze` — analyzes question papers to extract metadata.

## Configuration

### Environment Variables

- **GEMINI_API_KEY** (required) - Your Google AI API key
- **GEMINI_MODEL** (optional) - Model to use (default: `gemini-2.0-flash-exp`)
  - `gemini-2.0-flash-exp` - Faster, experimental (recommended)
  - `gemini-1.5-pro` - Better quality, slower
  - `gemini-1.5-flash` - Balanced performance
- **GEMINI_API_VERSION** (optional) - API version (default: auto-detect)
  - `v1alpha` - For latest experimental models like gemini-2.0-flash-exp
  - `v1` - For stable models
- **PORT** (optional) - Server port (default: 8100)
- **GEMINI_TIMEOUT_MS** (optional) - Request timeout in milliseconds (default: 120000)
- **MAX_CONCURRENT_EVALUATIONS** (optional) - Max parallel evaluations (default: 1)
- **MIN_EVALUATION_INTERVAL_MS** (optional) - Min delay between requests (default: 1500)

### Troubleshooting Timeouts

If you see timeout errors:

1. **Increase timeout**: Set `GEMINI_TIMEOUT_MS=180000` (3 minutes)
2. **Reduce file sizes**: Compress PDFs or reduce image quality
3. **Process fewer files**: For bulk uploads, submit smaller batches
4. **Check Gemini status**: Visit https://status.cloud.google.com/
5. **Verify model availability**: Some models require API v1alpha access

### Rate Limiting

The service automatically throttles requests to respect Gemini API limits:

- Only 1 concurrent evaluation by default
- Minimum 1.5 seconds between requests
- Adjust `MAX_CONCURRENT_EVALUATIONS` and `MIN_EVALUATION_INTERVAL_MS` if you have higher quota
